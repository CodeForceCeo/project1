# Pocket Codex

Личный мост **ChatGPT на телефоне → API на вашем Windows PC → Codex App Server**. Мобильная панель показывает задачи, промежуточные сообщения, действия, запросы разрешений и результаты.

## Что работает

- Асинхронная очередь: одна задача выполняется, остальные ждут; повтор запроса с тем же `requestId` не запускает копию.
- Реальный локальный Codex через официальный stdio-протокол App Server. Используется текущая авторизация Codex; дополнительный OpenAI API key мосту не нужен.
- Статусы `queued`, `running`, `waiting_approval`, `completed`, `failed`, `interrupted`, отмена и продолжение завершённого чата.
- История последних 100 задач хранится локально. Панель обновляется каждые 1,8 секунды; последние 30 задач доступны в списке. После перезапуска незавершённая работа не повторяется.
- Отдельные ключи для владельца и ChatGPT. GPT Actions не может подтверждать собственные запросы разрешений.
- Опциональный Windows MCP: снимок основного экрана, клики, Unicode-ввод, клавиши, прокрутка.
- Адаптивная русская панель, устанавливаемая на домашний экран браузером через веб-манифест.
- Node.js без сторонних npm-зависимостей; тесты на Windows и Linux в GitHub Actions.

**Граница интеграции:** проект запускает собственный процесс установленного Codex App Server. Он не перехватывает открытый чат приложения Codex и не управляет его кнопками. История App Server сохраняется средствами Codex. Проект не является RDP/видеотрансляцией: панель показывает текстовый ход работы, а снимки экрана используются агентом при включённом Desktop MCP.

## Быстрый запуск на Windows

Нужны Node.js 22+, Git и установленный Codex с рабочей авторизацией (`codex login`).

```powershell
git clone https://github.com/CodeForceCeo/project1.git
cd project1
npm run setup -- --desktop
npm run doctor
npm start
```

Откройте **http://127.0.0.1:4317**. Введите `panelToken` из `config.local.json`. Файл создаётся автоматически; ключи не выводятся в консоль и исключены из Git. `--desktop` добавляет инструменты управления экраном. Без него доступны shell/файлы и настроенные в Codex инструменты.

`npm run doctor` проверяет запуск App Server, авторизацию и список моделей без отправки задачи модели. Модель по умолчанию берётся из настроек Codex. В `config.local.json` можно задать `model` из списка диагностики.

По умолчанию рабочая папка — `.local/workspace`. Чтобы изменить её, задайте **существующий абсолютный путь** в `workspace` и перезапустите сервер. Если `codex` не найден, задайте полный путь к `codex.exe` в поле `codex` (например, путь из `Get-Command codex`). При установке Codex через npm на Windows укажите настоящий исполняемый файл, а не `.cmd`-обёртку.

## Подключение без домена

Для первого подключения поддержан **Cloudflare Quick Tunnel**. Он выдаёт временный HTTPS-адрес без регистрации и домена, но предназначен для тестирования; адрес меняется при каждом запуске. Для постоянного использования нужен стабильный HTTPS-адрес и обычный управляемый туннель.

1. Скачайте `cloudflared.exe` с [официальной страницы Cloudflare](https://developers.cloudflare.com/tunnel/downloads/) в `.local/cloudflared.exe`.
2. Остановите `npm start` через Ctrl+C.
3. Выполните:

```powershell
powershell -NoProfile -ExecutionPolicy Bypass -File scripts/connect.ps1
```

Скрипт запускает туннель, записывает его адрес в `publicUrl`, затем запускает сервер. Оставьте окно открытым. Он напечатает адрес панели для телефона и адрес схемы GPT Actions. При Ctrl+C туннель завершается. Скрипт не добавляет автозапуск и не открывает порт роутера.

Если используется собственный туннель, установите `publicUrl` равным его HTTPS origin **без завершающего слеша** и запустите `npm start`. Сервер слушает только `127.0.0.1`; обратный прокси должен передавать корректный Host. Не публикуйте весь каталог проекта через файловый веб-сервер.

## Команды из ChatGPT на телефоне

Это подключение настраивается в **личном Custom GPT с Actions**, а не автоматически во всех обычных чатах ChatGPT. Возможность создания GPT/Actions зависит от вашего аккаунта.

1. В редакторе собственного GPT создайте личный GPT «Мой компьютер».
2. Вставьте инструкции из [docs/gpt-instructions.md](docs/gpt-instructions.md).
3. В Actions импортируйте `https://ВАШ-АДРЕС/openapi.json`.
4. Authentication: **API Key → Bearer**. Ключ — `actionsToken` из `config.local.json`, **не panelToken**.
5. Сохраните GPT с видимостью **только для себя**. Не публикуйте GPT с личным ключом управления ПК.
6. Откройте этот GPT в ChatGPT на телефоне: «Создай в рабочей папке файл plan.md с планом на неделю».
7. Перейдите по выданной ссылке, войдите с `panelToken` и при необходимости ответьте на запрос Codex. В дальнейшем спрашивайте GPT «Какой статус?» / «Покажи результат».

После перезапуска Quick Tunnel повторно импортируйте схему с новым адресом. Во время долгих задач API сразу возвращает ID; запрос не держится до завершения. ChatGPT показывает статус по запросу, а **живые обновления находятся в открытой панели**. Push-уведомлений и фоновой отправки сообщений в закрытый ChatGPT нет.

Можно использовать панель самостоятельно, без Custom GPT: она передаёт текст напрямую Codex и показывает тот же результат.

## Разрешения и управление компьютером

Потоки создаются с `approvalPolicy: untrusted` и `sandbox: workspace-write`. Codex может запросить разрешение для shell-команды или изменения. Разрешения выдаются владельцем в панели на конкретный запрос. Настройки и ограничения организации в Codex сохраняют приоритет; мост не снимает их.

При `desktop: true` локальный MCP управляет **всем интерактивным рабочим столом**, независимо от файловой песочницы shell. Он работает с правами текущего пользователя, не проходит UAC/экран блокировки и не поддерживает другие мониторы. Компьютер должен быть включён, не спать, а пользовательская сессия — разблокирована. Не включайте Desktop MCP для недоверенных задач. Проект не гарантирует подтверждение каждого клика: одобрение shell и действия MCP — разные механизмы.

Остановка отправляет `turn/interrupt`, затем завершает принадлежащий задаче процесс. На Windows завершается его дерево процессов. Уже сделанные изменения не откатываются. По истечении 30 минут задача останавливается; лимит можно изменить через `taskTimeoutMs`.

Встроенный сервер предназначен для одного владельца. Ключ Actions позволяет запускать задачи; относитесь к нему как к доступу к компьютеру. Для отзыва замените ключ в конфиге, перезапустите сервис и обновите настройки GPT. Для полного отключения остановите сервер и туннель.

## Разработка и проверка

```powershell
npm test
npm run check
npm run doctor
```

Тесты используют подставной RPC для проверки событий/сбоев/разрешений и настоящий локальный HTTP-сервер для проверки авторизации, origin/host, очереди и сохранения состояния. Реальная проверка модели выполняется вручную через панель и расходует лимиты Codex.

```text
src/rpc.mjs         JSON-RPC / запуск и остановка Codex
src/runner.mjs      задачи, события, разрешения, отмена
src/store.mjs       локальная история и идемпотентность
src/server.mjs      HTTP API, авторизация, статические файлы
src/openapi.mjs     схема GPT Actions
src/desktop-mcp.mjs инструменты Windows для Codex
public/            мобильный интерфейс
scripts/           настройка, запуск, диагностика, туннель
test/              автоматические тесты
```

## Ограничения и диагностика

| Симптом | Действие |
|---|---|
| `codex` не найден | Укажите путь к `codex.exe`, проверьте `npm run doctor` |
| Нет авторизации | Выполните `codex login` локально |
| `waiting_approval` | Откройте панель и ответьте на запрос |
| Неизвестный запрос RPC | Версия протокола изменилась; запрос отклоняется с ошибкой, а не одобряется автоматически |
| `Host не разрешён` | Проверьте `publicUrl`, перезапустите сервер |
| Телефон не видит localhost | Используйте HTTPS-адрес туннеля |
| GPT потерял подключение | ПК/туннель должны работать; обновите схему при смене адреса |
| Windows не принимает ввод | Проверьте разблокированную сессию и отсутствие окна UAC |

Протокол сверялся с установленным Codex и [официальной документацией App Server](https://learn.chatgpt.com/docs/app-server). Интеграция ChatGPT основана на [GPT Actions](https://developers.openai.com/api/docs/actions/getting-started). [Quick Tunnel](https://developers.cloudflare.com/tunnel/get-started/quick-tunnels/) служит временным способом подключения. У OpenAI также есть собственный [Remote](https://developers.openai.com/blog/mastering-codex-remote-for-engineering); этот репозиторий — независимый личный мост.
